⚙️ Configurações da IA

Recomendado: modo proxy — a chave fica no servidor e nunca chega ao navegador. O modo "chave direta" serve apenas para teste rápido e expõe a chave a qualquer pessoa que abrir a página.

O proxy recebe a pergunta, injeta a chave no servidor e devolve a resposta do Gemini. Nenhuma chave no HTML, no localStorage ou na URL.
Ver código do proxy (Cloudflare Worker — grátis, ~2 min) 
export default {
  async fetch(req, env) {
    const ORIGIN = '*'; // troque pelo dominio do site, ex: 'https://iadobook.pages.dev'
    const cors = {
      'Access-Control-Allow-Origin': ORIGIN,
      'Access-Control-Allow-Headers': 'Content-Type',
      'Access-Control-Allow-Methods': 'POST, OPTIONS'
    };
    if (req.method === 'OPTIONS') return new Response(null, { headers: cors });
    if (req.method !== 'POST')
      return new Response('Method Not Allowed', { status: 405, headers: cors });

    const { model, ...body } = await req.json();
    if (!model) return new Response(JSON.stringify({ error: { message: 'Modelo não informado' } }), { status: 400, headers: cors });
    const r = await fetch(
      'https://generativelanguage.googleapis.com/v1beta/models/'
        + encodeURIComponent(model) + ':generateContent',
      { method: 'POST',
        headers: { 'Content-Type': 'application/json',
                   'x-goog-api-key': env.GEMINI_API_KEY },
        body: JSON.stringify(body) }
    );
    return new Response(await r.text(),
      { status: r.status, headers: { ...cors, 'Content-Type': 'application/json' } });
  }
}
Deploy: workers.cloudflare.com → Create Worker → colar o código → Settings → Variables → criar o secret GEMINI_API_KEY → Deploy. Depois cole a URL do Worker no campo acima.
Enviada em header (x-goog-api-key), nunca na URL — evita vazamento por histórico, logs e referrer. Mesmo assim continua visível no DevTools de quem abrir a página.
Se o modelo não existir para sua chave/projeto, o sistema tenta automaticamente os alternativos.
Substitui automaticamente [Nome] nos scripts de atendimento da base.
